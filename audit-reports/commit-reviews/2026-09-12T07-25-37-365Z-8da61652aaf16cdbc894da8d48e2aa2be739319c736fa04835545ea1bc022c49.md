- `src/authoring/elicitation-guard.js:49` (added line)
- **Observed**: `candidateDocs.sort((left, right) => left.localeCompare(right))` — locale-dependent collation; on the real canonical set it emits `multidoc-feature_SCHEMA.md` between `FR.md` and `NFR.md` and `USE_CASES.md` before `USER_STORIES.md`.
- **Expected**: staged `NFR.md` NFR-DETERMINISM-1: "Target documents SHALL use locale-independent code-point ordering" — code-point order puts `USER_STORIES.md` before `USE_CASES.md` and `<spec>_SCHEMA.md` last.
- **Trigger**: any multi-document first-write refusal (e.g. `createSpec` on a fresh spec) — `error.documents` is emitted in locale order on every runtime, varying with host ICU data.
- **Impact**: the typed refusal contract is non-deterministic across locales and violates the spec clause; the staged test (`safe-authoring.steps.mjs:512-513`) sorts the expected value with the same `localeCompare`, a self-oracle that cannot catch the breach.
- **Evidence**: `elicitation-guard.js:49`; staged `NFR.md` NFR-DETERMINISM-1; node proof over the 14 canonical names (`equal:false`).

**P2 — correctness-2: capacity eviction can drop a ticket belonging to the refused batch, causing a second refusal**
- `src/authoring/elicitation-guard.js:18-26` (added lines; batch re-record loop at 59-61)
- **Observed**: at `MAX_ELICITATION_TICKETS` capacity `_remember` unconditionally deletes the oldest ticket before adding a new key. A refused batch mixing already-ticketed and new documents records in sorted order; a new key can evict the oldest ticket, which may belong to a member of the same batch.
- **Expected**: staged `FR.md` FR-5: "Once a ticket is recorded for a spec plus document during the cached authoring-service lifetime, subsequent writes to that target SHALL proceed without a second refusal" — unconditional; NFR-COMPAT-1 likewise requires a recorded ticket's retry to succeed.
- **Trigger**: 10000 tickets recorded; `spec-first/README.md` and `spec-first/FR.md` are the two oldest. Batch `[README.md, FR.md, NFR.md]` is refused (NFR.md new); recording inserts NFR.md and evicts `spec-first/README.md`. A later write to still-missing `spec-first/README.md` is refused a second time. The staged edge test (`authoring-elicitation-edges.test.mjs:104-123`) constructs exactly this state but only asserts the second-oldest ticket survives.
- **Impact**: second `ELICITATION_REQUIRED` stop for an already-ticketed target at the designed capacity boundary; automatic flows hit an unexpected extra refusal.
- **Evidence**: `elicitation-guard.js:22-24` (unconditional oldest eviction), `:59-61` (batch re-record); staged `FR.md` FR-5; staged test lines 104-123.
