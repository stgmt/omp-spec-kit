### Confirmed findings

#### [P1] ROADMAP added to FIXED_DOCUMENT_FILES and DOCUMENT_KINDS causes runInventory to report ROADMAP as missing canonical document for all non-roadmap specifications
- **File path**: `src/kernel/types.js`
- **Line range**: `20-42`
- **Defect class**: `correctness`
- **Observed behavior**: By registering `ROADMAP: 'ROADMAP.md'` into `FIXED_DOCUMENT_FILES` (lines 20-23) and `'ROADMAP'` into `DOCUMENT_KINDS` (lines 39-42), `expectedFilename(kind, slug)` in `src/kernel/query/service.js` returns `'ROADMAP.md'` unconditionally for all specification slugs. As a result, `missingCanonicalKinds(slug, acceptedKinds)` requires `ROADMAP.md` across every specification in the repository, flagging `missingCanonicalDocuments: ['ROADMAP']` for all standard (non-roadmap) specifications.
- **Expected behavior**: Per domain invariant `REQ-1` in `.specs/roadmap-roadmaps/REQUIREMENTS.md`, `ROADMAP.md` is a canonical document exclusively for specifications whose slug begins with `'roadmap-'`. Standard specifications must not expect `ROADMAP.md`, and `runInventory` must return `missingCanonicalDocuments: []` for healthy standard specs.
- **Trigger scenario**: Call `runInventory` (via MCP tool `spec_catalog` with `view: "inventory"`) on any repository containing non-roadmap specifications (e.g. `spec-mcp-operations` or `plugin-distribution`). `missingCanonicalDocuments` returns `["ROADMAP"]`.
- **Impact**: Breaks inventory query correctness for all non-roadmap specifications across the repository, causing MCP clients, linters, and downstream tooling to perceive all non-roadmap specifications as incomplete/deficient.
- **Repository evidence**:
  - `src/kernel/types.js` lines 20-23 and 39-42 added `ROADMAP: 'ROADMAP.md'` to `FIXED_DOCUMENT_FILES` and `'ROADMAP'` to `DOCUMENT_KINDS`.
  - `src/kernel/query/service.js` lines 923-935: `expectedFilename` unconditionally returns `FIXED_DOCUMENT_FILES[kind]`, without checking `slug.startsWith('roadmap-')`.
  - Live execution of `runInventory` on the snapshot codebase confirmed: `spec-mcp-operations` reports `missingCanonicalDocuments: ['ROADMAP']`, while before this addition it reported `[]`.
