# User Stories

## US-1: Stopped before inventing numbers

As a spec author, I want the first write to a missing canonical Markdown document to stop me once and point at the elicitation memo so that I ask about gaps instead of inventing limits and loudness figures.

## US-2: Reviewer who sees grounded specs

As a reviewer, I want specs whose numbers come from sources or explicit answers so that review checks meaning instead of hunting invented constants.

## US-3: Automation owner with working headless flows

As an automation owner, I want automatic runs to pass the one-time stop with a single retry so that nightly checks keep working without a human answering questions.

## US-4: Maintainer who edits one text

As a maintainer, I want the rule text to live in exactly one memo and one short shared hint so that a wording fix needs a single edit.

## US-5: Specification owner with predictable boundaries

As a specification owner, I want existing documents, previews, feature files, and unrelated paths to remain unaffected so that the guard does not change ordinary authoring.
