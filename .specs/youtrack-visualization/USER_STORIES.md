# User Stories

## US-1: See a task neighborhood

As a task owner, I want the issue panel to show related requirements and acceptance criteria so that I can navigate work without leaving the tracker.

## US-2: See the full corpus

As a planner, I want a full-corpus board with kind filters so that I can understand scope and dependencies.

## US-3: Trust projection identity

As an operator, I want stable SpecId, source hash, and provenance so that a card can be traced back to its specification node.

## US-4: Change task state safely

As a reviewer, I want Approve, Verify, and Reopen to update governed task state so that tracker actions cannot silently diverge from the specification.

## US-5: Operate a repairable adapter

As an integration maintainer, I want ports, pure translators, parity checks, and a commit marker so that transport failures and tracker drift do not corrupt the last complete read model.

## US-6: Explore one consistent board

As a user, I want Flow, Cluster, and Lineage views to show the same snapshot so that changing a visualization cannot change the meaning of the graph.
