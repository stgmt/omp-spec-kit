# Общий глоссарий проекта
Status: DRAFT
## Назначение
Один поддерживаемый через MCP файл `GLOSSARY.md` на проект содержит принятые термины, определения и явно запрещённые варианты. Проект — это идентификатор `owner/project` реестра; глоссарий привязан к репозиторию проекта и не делится между проектами, даже если они используют один репозиторий. Все спецификации проекта используют его как общий источник, а не ведут копии. Этот документ описывает новую возможность spec-kit, а не заявляет, что она уже работает.
## Границы
Входит: обнаружение (включая ссылку в MCP-инструкциях и в сгенерированном `AGENTS.md` проекта), чтение, поиск, создание и изменение файла через инструмент `spec_glossary` с ожидаемым хешем содержимого, проверка используемой версии при записи спецификации параметром `spec_patch.glossarySha256`, обязательный гейт до содержательной правки спецификации, диагностика и понятные действия для агента, изоляция проектов и конкурирующие изменения. Не входит: автоматическое понимание смысла и доказательство, что агент прочитал текст; решение владельца о значении термина остаётся в данных проекта.
## Связи и источники
Реестр и права — `spec-registry-service`; общие MCP-операции — `spec-mcp-operations`; гейт допуска описывает этот документ (FR-8), отдельной спеки `spec-readiness-gate` в корпусе нет. Идемпотентность записи и межпроцессная блокировка — существующий `src/authoring/transactions.js` (`withWriteLock`, журнал по `requestId`), второй протокол не вводится. Глоссарий расширяет существующие контракты, не заменяет их. Подтверждённые ограничения текущей версии и незакрытые вопросы — в RESEARCH.md. Реализация и доставка пока не доказаны.
