# Общий глоссарий проекта

Status: DRAFT

## Назначение
Один поддерживаемый через MCP файл `GLOSSARY.md` на проект содержит принятые термины, определения и явно запрещённые варианты. Все спецификации проекта используют его как общий источник, а не ведут копии. Этот документ описывает новую возможность spec-kit, а не заявляет, что она уже работает.

## Границы
Входит: обнаружение, чтение, поиск, создание и изменение файла; проверка используемой версии при записи спецификаций; диагностика и понятные действия для агента; изоляция проектов и конкурирующие изменения. Не входит: автоматическое понимание смысла и доказательство, что агент прочитал текст; решение владельца о значении термина остаётся в данных проекта.

## Связи и источники
Реестр и права — `spec-registry-service`; общие MCP-операции — `spec-mcp-operations`; правила готовности — `spec-readiness-gate`. Глоссарий расширяет их, не заменяет. Подтверждённые ограничения текущей версии и незакрытые вопросы — в RESEARCH.md. Реализация и доставка пока не доказаны.
