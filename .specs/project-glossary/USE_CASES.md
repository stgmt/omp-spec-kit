# Сценарии использования

1. Агент выбирает проект, обнаруживает существование глоссария в подсказке и в `AGENTS.md`, читает файл через `spec_documents {action:"glossaryRead"}` и передаёт полученный `contentSha256` в `spec_patch.glossarySha256` при сохранении спецификации.
2. Автор предлагает новое название или изменение определения: читает действующий файл, уточняет смысл по доступным решениям, вносит изменение через `spec_patch` с ожидаемой версией, получает новую версию и продолжает авторинг.
3. Два автора изменяют один файл: сохранение первого проходит, второй получает конфликт и перечитывает источник до повторной осмысленной правки.
4. В спецификации встречается запрещённая форма: агент получает место и рекомендованный термин, исправляет текст и повторяет проверку. Если новое слово нельзя распознать автоматически, агент сам проверяет значение; сервер не заявляет обратного.
5. В новом проекте владелец создаёт исходный файл действием `spec_patch {intent:"createGlossary"}` до первого содержательного авторинга; файл не создаётся автоматически, а операции чтения, настройки и создания не требуют заранее существующего файла.
