# Сценарии использования

1. Агент выбирает проект, обнаруживает существование глоссария в подсказке, читает файл и его версию, затем использует эту версию при подготовке и сохранении спецификации.
2. Автор предлагает новое название или изменение определения: читает действующий файл, уточняет смысл по доступным решениям, вносит изменение через MCP с ожидаемой версией, получает новую версию и продолжает авторинг.
3. Два автора изменяют один файл: сохранение первого проходит, второй получает конфликт и перечитывает источник до повторной осмысленной правки.
4. В спецификации встречается запрещённая форма: агент получает место и рекомендованный термин, исправляет текст и повторяет проверку. Если новое слово нельзя распознать автоматически, агент сам проверяет значение; сервер не заявляет обратного.
5. В новом проекте владелец создаёт исходный файл до первого содержательного авторинга; операции чтения, настройки и создания файла не требуют заранее существующего файла.
