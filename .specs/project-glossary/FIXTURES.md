# Данные для проверки

- Проект A с двумя спеками и глоссарием: термин «объект пула», запрещённая форма «сиденье»; проект B в той же репозитории с независимым термином. Значения здесь тестовые и не подменяют реальный глоссарий Tokenplan.
- Пустой новый проект и проект с недоступным хранилищем: оба блокируют содержательную запись, но дают разные причины; настройка и чтение существующей спеки остаются доступными.
- Два автора с одной версией и разные изменения; отдельный случай смены версии между предварительным просмотром и применением.
- Одна запрещённая форма в прозе, та же строка в кодовом блоке, часть более длинного слова, смешанный регистр и Unicode NFC/NFD. Утверждать ожидаемую строку и столбец исходника.
- Пользователь с правом чтения и пользователь без области доступа; проверять отсутствие чужих содержимого и метаданных в отказе.
- Потерянный ответ после сохранения; повтор того же идентификатора запроса и запрос с другим содержимым под тем же идентификатором.
- Локальный и сетевой MCP с общими сценариями авторинга и проверка фактически установленного сервера; не заменять прямым вызовом внутренней функции.

Эти данные задают проверяемые случаи, но не являются результатом теста и не утверждают наличие готовой реализации.

- Правила Git для отдельной ветки: обычный потребитель не может изменить её напрямую; сервис с проверенными правами может записать разрешённое изменение.

- Многостраничный ответ: точные байты UTF-8, граница внутри многобайтного символа, изменение текущего файла после первой страницы; проверять непрерывность, фиксированную ревизию, длину и SHA-256.
- Разметка `за**прещённая** форма` — запрещённая форма с колонкой 1; `a Straße b` при запрещённой `strasse` — колонка 3. Кодовый фрагмент разрывает совпадение.
- Два экземпляра, атомарный push двух ссылок и отказ каждой из них; внезапная остановка до и после принятия Git, повтор запроса, тот же requestId с другим содержимым и недоступная история.
