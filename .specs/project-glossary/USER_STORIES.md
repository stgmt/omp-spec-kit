# Истории пользователей

- Автор спецификации хочет видеть действующие слова проекта до изменения текста, чтобы не вводить второе название того же понятия.
- Владелец проекта хочет один управляемый источник определений и запрещённых форм, общий для всех спецификаций, без незаметного расхождения копий.
- Агент хочет получить понятную ошибку и точное следующее действие при отсутствии файла, устаревшей версии, запрещённом слове или нехватке прав.
- Администратор нескольких проектов хочет, чтобы поиск и изменение терминов одного проекта не раскрывали данные другого.
