# v0.3.0 MCP advisory

## Affected release

`omp-spec-kit` v0.3.0 contains the read-only MCP server, but its packaged `.mcp.json` sets the server working directory to the plugin package. In an ordinary OMP session this can make the server inspect the package folder instead of the project where OMP was started, producing an empty or wrong specification result.

## User action

Do not rely on v0.3.0 MCP query results for project inventory, traceability, diagnostics, overview, or Markdown inventory. Upgrade to v0.3.1 after its candidate evidence is published, reload plugin metadata, and start a fresh OMP session before invoking MCP tools.

## What is not affected

This advisory does not rewrite the v0.3.0 tag or release history, and it does not add any mutation capability. The v0.1 `spec_inventory` OMP tool remains a separate read-only surface.

## v0.3.1 release condition

v0.3.1 is not released by this document. It will be published only after its candidate archive, tag, Docker BDD messages, public-safety receipt, v0.3.0 source proof, upgrade receipt, rollback receipt, and per-requirement receipts agree.
