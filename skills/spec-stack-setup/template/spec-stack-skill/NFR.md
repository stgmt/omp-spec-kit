# Non-Functional Requirements

## NFR-1 — Кроссплатформенность

Скилл ДОЛЖЕН работать на Windows, macOS и Linux: только `node >= 22` и `docker compose` v2, без платформенных shell-скриптов; все скрипты — на Node.js.

## NFR-2 — Идемпотентность

Повторный запуск ДОЛЖЕН приводить стек к целевому состоянию без дублей: группы и проект создаются по find-or-create, шаблон спеки перезаписывает документы, дашборд перевыдаётся заново.

## NFR-SEC-1 — Креды не покидают localhost

Все сервисы ДОЛЖНЫ слушать только `127.0.0.1`; пароль администратора и bridge-токен живут в файлах скила и никуда не отправляются, кроме самого YouTrack и реестра.
