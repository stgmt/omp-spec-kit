# Acceptance Criteria

## AC-1.1 — Стек отвечает

**Given** чистая машина без поднятых контейнеров, **when** выполнен `node setup.mjs`, **then** YouTrack отвечает 200 на :8089, а `/mcp` реестра отвечает 405 на :8644.

## AC-1.2 — Приложение установлено и подключено

**Given** стек поднят и визард пройден, **when** фаза установки завершилась, **then** приложение `spec-graph-app` видно в Apps, имеет `serviceUrl`/`serviceBridgeToken` и привязано к проекту DEMO.

## AC-1.3 — Ссылка ведёт на готовую доску

**Given** завершённый прогон, **when** админ открывает напечатанную ссылку, **then** дашборд «Spec Stack» показывает Spec Board во всю ширину со спекой `spec-stack-skill`.

## AC-2.1 — Шаблон проходит через MCP

**Given** реестр жив, **when** загрузчик отработал, **then** `spec_catalog` содержит `spec-stack-skill`, а каждый документ шаблона закоммичен ботом в specs.git.
